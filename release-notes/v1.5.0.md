## v1.5.0 — Delete retired Curb hubs

Hubs you've retired, replaced or moved to another Home Assistant install can now be deleted from the UI. Until now a Curb device could not be removed, and its entities sat at `unavailable` indefinitely.

### What's new

- **Delete a hub from its device page.** Settings → Devices & Services → Curb → the hub → ⋮ → **Delete**. Deleting removes the device and all its sensors and its Live Power Readings switch.
- **A clean removal.** The hub's persisted energy totals, dedup boundary, chip layout, cached readings, queued hub messages and per-circuit settings are discarded too, so it no longer appears in **Configure** and doesn't come back after a restart.
- **Online hubs are protected.** A hub that has posted data in the last 5 minutes can't be deleted, because its next POST would immediately re-create it. Home Assistant shows: *"Curb hub ‹serial› is still sending data… Power off the hub or point it away from Home Assistant, wait 5 minutes, then try again."*

### Upgrade notes

- No action required. Nothing changes for hubs you keep.
- To delete a hub that is still connected, power it off (or point its DNS/proxy away from Home Assistant) first, wait 5 minutes, then delete.

### Caveats

- If a deleted hub starts posting again later, it reappears as a new device and its energy counters start from zero. History already in the recorder is not deleted.
